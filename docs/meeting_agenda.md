# 🤝 첫 팀 미팅 안건 및 진행 가이드 (제안서)

> 이 문서는 4인 팀의 첫 오프라인/온라인 미팅을 효율적으로 이끌기 위한 진행 스크립트이자 안건 가이드입니다. 그대로 복사하여 단톡방이나 노션에 공유하셔도 좋습니다.

---

## 📅 미팅 개요
- **목적**: 120시간 텀 프로젝트 미션 이해, 베이스라인 코드 공유, 역할 분담 및 다음 목표 설정
- **소요 시간**: 약 1시간 예상

## 📝 진행 안건 (Agenda)

### 1. 미션의 본질과 목표 공유 (15분)
* **논의 내용**: 이 프로젝트는 단순한 헬로월드 챗봇이 아니라, 실제 서비스 수준의 '웹 서버, DB, 보안, 실시간 스트리밍'이 모두 들어간 종합 엔지니어링 미션임을 공유합니다.
* **액션 아이템**:
  - 준비한 **[초정밀 현미경 학습 가이드](deep_dive_study_guide.md)**의 `Part 1. 미션의 본질적 함의` 부분을 다 함께 가볍게 읽어봅니다.

### 2. 베이스라인 코드(뼈대) 공개 및 접근 방식 합의 (15분)
* **제안할 멘트**:
  > "미션 요구사항이 꽤 방대해서, 제가 AI의 도움을 받아 미션 조건을 100% 만족하는 '완성된 뼈대 코드'를 미리 구축해 보았습니다. 백지에서 시작하면 기한 내에 완성하기 벅찰 수 있으니, **이 완성된 코드를 우리의 베이스캠프로 삼고 각자 관심 있는 파트를 맡아 코드를 뜯어보며 완벽히 내 것으로 만드는(분석/개선) 방식**으로 진행하는 게 어떨까요?"

### 3. 강점과 관심사 맞춤형 역할 분담 (15분)
각자의 관심사와 평소 다뤄보고 싶었던 영역을 고려하여 다음과 같이 역할을 나눕니다.

| 역할 (Role) | 주요 담당 기술 | 설명 |
| :--- | :--- | :--- |
| **프론트엔드 & UI 담당** | HTML, TailwindCSS, JS 상태 관리 | 사용자의 눈에 바로 보이는 채팅창 화면과 버튼 동작, 애니메이션 등을 책임지는 파트 |
| **데이터 & 로깅 담당** | SQLite 조회, HTML 렌더링 | 사용자 로그를 화면에 띄우고 데이터가 어떻게 안정적으로 저장되는지 검증하고 관리하는 파트 |
| **인증 & 서버 로직 담당** (본인 추천) | FastAPI 라우팅, JWT, Bcrypt | 로그인/회원가입 흐름과 비밀번호 암호화 등 백엔드의 뼈대와 보안을 통제하는 파트 |
| **AI 파이프라인 & 아키텍처 담당** | 비동기 SSE, 타임아웃, 예외 처리 | 가장 복잡한 스트리밍 로직 전담 및 전체 시스템의 예외 상황(에러/지연)을 방어하는 파트 |

### 4. 다음 미팅까지의 '최소 목표(숙제)' 설정 (15분)
* **목표**: 각자 맡은 파트의 '1타 강사' 되기!
* **숙제 내용**:
  - 오늘 공유한 **학습 가이드**와 **소스 코드**를 바탕으로, 본인이 맡은 파트가 어떻게 돌아가는지 완벽히 이해해 오기.
  - 다음 미팅에서는 각자 5~10분씩 자신의 파트 코드 흐름을 다른 팀원들에게 설명(미니 세미나)해 주기.
  - (선택) 코드를 보다가 아쉬운 점이나 개선하고 싶은 디자인/기능이 생각나면 메모해 오기.
